# Which AOUs correspond to nontarget species.

Downloaded using the rdataretriever in June 2022. For inclusion in
package vignettes, function testing. Citation needed!

## Usage

``` r
nontarget_species
```

## Format

A data frame with 263 rows and 4 variables:

- AOU:

  AOU

- english_common_name:

  English common name

- genus:

  genus

- species:

  species
