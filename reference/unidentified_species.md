# Table of AOUs corresponding to unidentified species.

This data table is used internally to filter out unidentified species
based on their AOUs. It is derived from the species table available in
Pardieck et al. (2019)

## Usage

``` r
unidentified_species
```

## Format

A data frame with 72 rows and 4 variables:

- AOU:

  AOU

- english_common_name:

  English common name

- genus:

  genus

- species:

  species

## References

- Pardieck, K. L., Ziolkowski, D. J., Lutmerding, M., Aponte, V., &
  Hudson, M.-A. (2019). North American Breeding Bird Survey Dataset
  1966—2018, version 2018.0. U.S. Geological Survey.
  https://doi.org/10.5066/P9HE8XYJ
