# Toy data frame of abundances and species mean sizes (for vignettes)

This data table is a toy data frame for the vignettes. It has abundances
and mean body sizes for 5 species to make up a hypothetical community.

## Usage

``` r
toy_size_community
```

## Format

A data frame with 5 rows and 3 variables:

- mean_size:

  Mean mass, in g

- abundance:

  Number of individuals to simulate masses for

- sim_species_id:

  ID
