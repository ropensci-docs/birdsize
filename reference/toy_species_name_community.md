# Toy data frame of abundances and species names (for vignettes)

This data table is a toy data frame for the vignettes. It has abundances
and scientific names for 5 species to make up a hypothetical community.

## Usage

``` r
toy_species_name_community
```

## Format

A data frame with 5 rows and 2 variables:

- scientific_name:

  Scientific name

- abundance:

  Number of individuals to simulate masses for
